# Star Trek The Next Generation Episode Finder
This app is under construction! But its primary funcition is to use filters (such as Characters or Aliens) to find related episodes for Star Trek TNG theme binging. If you want to watch all the Data episodes, or all the Spooky episodes, that's what it's here for. I plan to make this pretty deep cut but it will take time to seed the database. Planed filters include: Characters, Themes (Generes), Aliens, Directors, Writers, and Miscellaneous (Fan Favorites, Heart of Star Trek, and Editor's Picks).

There are 178 episodes of TNG and each will have around 6 filters so this will take some time to seed.

## Stack
The stack is React, ASP.NET, Dapper, PostgresSQL. It is a kind of funny stack but I wanted to practice React, C#, and MS SQL - but I chose PostgreSQL over MS SQL Server as it was a PITA to set up in my Mac development environment. The two are quite similar for what I am trying to do (i.e. Join Tables and simple Stored Procudures).
